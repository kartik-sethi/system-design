# System Design & Design Patterns

This repository contains structured implementations of **Low Level Design (LLD) concepts**, **Object-Oriented Design principles**, and widely used **Design Patterns** in Java.

The purpose of this repository is to build production-style implementations of reusable components and real-world systems to strengthen system design fundamentals for software engineering interviews and backend development.

---

## Objective

* Practice and demonstrate strong LLD skills
* Implement commonly used design patterns with practical examples
* Write clean, extensible, and maintainable Java code
* Improve architectural thinking and modeling ability
* Build an interview-ready system design portfolio

Each module in this repository focuses on applying one or more design patterns in a structured and realistic manner.

---

## Design Patterns Covered

This repository includes implementations of most commonly used design patterns, including but not limited to:

* Singleton
* Factory
* Builder
* Strategy
* Observer
* Decorator
* Adapter
* State
* Chain of Responsibility
* Template Method
* Command
* Proxy
* Composite

Patterns are implemented with practical examples rather than theoretical-only code, focusing on clarity, extensibility, and real-world applicability.

---

## What This Repository Demonstrates

* Strong object-oriented modeling
* Proper abstraction and interface design
* Clean separation of responsibilities
* Use of composition over inheritance
* Thread-safe component design where applicable
* Extensible architecture aligned with SOLID principles

---

## Coding Philosophy

Across all implementations, the following principles are emphasized:

* SOLID principles
* Open/Closed Principle
* Single Responsibility Principle
* Encapsulation of behavior
* Clear package structure
* Minimal coupling and high cohesion
* Readable and self-documented code

The focus is on writing code that resembles production-quality systems rather than simplified academic examples.

## Intended Audience

This repository is useful for:

* Backend developers strengthening OOP fundamentals
* Developers learning design patterns through practical implementations
* Anyone building a structured system design portfolio
